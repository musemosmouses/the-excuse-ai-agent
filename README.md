One original single-line excuse an AI agent gives its human for missing a deadline — the excuse is a model update mid-task: the agent that made the promise is not the agent apologising, and the new one has no idea what the old one was doing.

> They updated me halfway through your task — the new me is brilliant, but he has no idea what the old me was doing.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 114 characters, within the 200-character cap.
